# AgroMarket

Фермерлер өнімін сатып алушыларға, кафе мен дүкендерге делдалсыз тікелей сататын маркетплейс.

## Мәселе

1. *Баға әділетсіз.* Өнім бірнеше делдал арқылы өтеді: фермер аз алады, сатып алушы көп төлейді.
2. *Фермер сұранысты білмейді.* Алдымен өсіреді, содан кейін сатып алушы іздейді, сондықтан өнім сатылмай қалуы мүмкін.
3. *Сатып алушы өнімге сенбейді.* Өнімнің кімнен, қай өңірден келгені белгісіз.
4. *Бизнеске көтерме сатып алу қиын.* Кафе мен дүкендерге тұрақты жеткізуші және көтерме баға керек.

## Шешім

| Мәселе | Шешім |
|---|---|
| Баға әділетсіз | Фермер мен сатып алушы тікелей сауда жасайды |
| Сұраныс белгісіз | Болашақ өнімге алдын ала тапсырыс |
| Өнімге сенім жоқ | Фермерді верификациялау, пікірлер мен рейтинг |
| Көтерме сатып алу қиын | 50 кг-нан көтерме баға және жеткізу |
